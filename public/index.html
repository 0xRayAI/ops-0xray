Multi-agent operations

One plane, one queue

Yes. AI Fleet OPS runs a multi-agent system on one plane and one queue so the job survives a context reset. Named roles share that queue, a human records the release, and model spend has a ceiling. You get there by writing the procedure on disk, filing every task as a ticket, and holding public posts until after GO.

What are the operating parts?

A fleet is running when one plane holds these four parts. A chat transcript cannot stand in for any of them.

Queue

One work queue

Every task is a ticket with an owner, a stage, and a state. Agent orchestration is that queue staying the record after the session ends.

Ownership

Named roles

Someone implements, someone reviews, someone coordinates. A human owner holds money, credentials, deletes, publishing, and taste.

Release

A recorded gate

Done is a receipt: a live URL, a registry view, a release, or a reviewer PASS on the pull request. A green build is the first check, not the receipt.

Spend

A compute ceiling

Write the spec before the cloud run. One deep-work run per ticket. New wakes go quiet when the weekly budget hits its hold line.

What is AI Fleet OPS?

AI Fleet OPS is the operating discipline for a multi-agent system in production. Named roles share one work queue, a written procedure, human-in-the-loop release gates, and a ceiling on model spend. The job has to be recoverable after a context window closes.

Who should read this manual?

Operators who run the queue, founders who own the outcome and the public voice, and engineering leads who own release gates and compute. The three start-here paths on this page point each job at the right guides.

How do agents keep a job after the context window closes?

The next session reads the procedure and the session ticket from disk, then resumes the same role on the same ticket. The long notes stay in the working page. The chat scroll is not the record.

When can the team post publicly?

The build lane and the go-to-market lane are separate. A review pass on a pull request leaves the public lane closed. This plant stays on hold until the human owner gives an explicit go.
