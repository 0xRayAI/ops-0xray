Operating guides

Yes. These six guides are the operating manual for a multi-agent team in production. Operators start by standing the team up. Founders start with the definition and the public lane. Engineering leads start with the queue and the release gate. Follow the path for your job, then use the glossary when a house file uses a shorter name.

Which path matches your job?

  • Operator. Stand the team up, then the control plane, then release gates.
  • Founder. What this discipline is, then build versus go-to-market, then model spend.
  • Eng lead. Control plane, then release gates, then model spend.
